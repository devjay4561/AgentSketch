# AgentSketch 사용안내

## 선행 자료를 한 장에 정리하는 방법

**파일 → 서비스 출시 준비 지도**에는 디자인·개발·QA·마케팅 자료가 출시 준비로 모이는 예시가 있습니다. 각 상자의 출처 이름은 설명용 텍스트이며, 외부 시스템 조회나 업무 승인은 실행하지 않습니다. 예시 내용은 자유롭게 수정하세요.

직접 시작하려면 다음처럼 구성할 수 있습니다.

1. 가운데에 **출시 준비** 같은 목표 상자를 만듭니다.
2. 왼쪽에 화면 시안·테스트 결과·안내 문서 등 선행 자료를 놓습니다.
3. 각 자료의 화면을 캡처해 붙이고, 텍스트나 메모로 확인 방법을 적습니다.
4. 각 선행 자료를 가운데 상자에 연결하고 선 위에 **확인 후**, **합산**, **담당자 검토** 등의 설명을 적습니다.
5. 관계가 복잡해지면 자료 묶음을 그룹으로 만들고 정렬하거나 자동 배치합니다.

PPT 슬라이드를 배경으로 쓸 때는 그림으로 복사하거나 화면을 캡처해 붙여넣으세요. 이미지 선택 후 **맨 뒤로 → 잠금**을 적용하면 위에 다른 요소를 놓기 편합니다. `.pptx` 원본을 직접 여는 기능은 없습니다.

## 만들고 편집하기

왼쪽 도구를 선택하고 작업지를 클릭하면 기본 크기로 추가합니다. 드래그하면 원하는 크기로 만듭니다. 도형과 텍스트를 **더블클릭**하거나 선택 후 **Enter**를 누르면 글자를 편집합니다. 오른쪽 **속성** 패널에서도 내용, 글자 크기, 정렬, 색상, 선 모양, 위치와 크기를 바꿀 수 있습니다.

글자 편집 중 **Ctrl+Enter**는 편집을 마치고, **Esc**는 이번 입력을 취소합니다. 요소 밖을 클릭해도 편집이 완료됩니다. 일반 Enter는 줄바꿈입니다.

- **선택·이동:** 요소를 클릭하고 끌어다 놓습니다. Shift를 누른 채 이동하면 가로 또는 세로 방향을 유지합니다.
- **여러 요소:** Shift+클릭으로 선택을 더하거나 빼고, 빈 공간을 드래그해서 선택 영역을 만듭니다.
- **크기 변경:** 요소 하나를 선택하고 모서리를 드래그합니다. Shift는 비율을 유지합니다. 이미지는 기본적으로 비율을 유지하며 Alt를 누르면 자유롭게 변경합니다.
- **정밀 이동:** 방향키로 1씩, Shift+방향키로 10씩 이동합니다.
- **겹친 요소:** 오른쪽 **레이어**에서 선택합니다. 목록을 더블클릭하면 해당 요소로 화면이 이동합니다.
- **찾기:** Ctrl+F 또는 레이어의 검색창에서 글자 내용을 검색하고 결과를 클릭합니다.

이미지 위에 글을 쓰려면 별도의 **텍스트**나 **메모** 요소를 올려놓으세요. 이미지·설명·표시 도형을 함께 선택해 그룹으로 만들면 함께 이동할 수 있습니다.

## 화면 이동과 확대

마우스 휠은 포인터가 가리키는 위치를 기준으로 확대·축소합니다. 화면을 옮길 때는 Space를 누른 채 드래그하거나 **화면 이동** 도구를 사용합니다. 마우스 가운데 버튼 드래그도 지원합니다.

**전체 보기**는 보드 전체가 화면에 들어오도록 맞춥니다. 왼쪽 아래 배율 숫자를 클릭하면 100%로 돌아갑니다. 오른쪽 아래 미니맵에서 위치를 클릭하면 그곳으로 이동합니다. 확대 범위는 10~400%입니다.

화면 아래의 **격자**는 배경 점을 표시하고, **맞춤**은 요소 이동 시 격자와 다른 요소의 가장자리·중앙에 맞춥니다. Alt를 누르고 이동·크기를 변경하면 맞춤을 잠시 끕니다.

## 연결선

**연결선(C)** 도구에서 시작 요소와 도착 요소를 차례로 클릭하세요. 시작 요소에서 도착 요소로 드래그해도 됩니다. 선택한 요소의 상하좌우 연결점을 다른 요소로 드래그하는 방식도 지원합니다.

선을 선택하고 끝점을 다른 요소로 드래그하면 연결 대상을 바꿀 수 있습니다. 연결되지 않은 도형을 선 위에 놓으면 중간 단계로 삽입하며, 수동 경로는 다시 계산합니다. 요소의 오른쪽 클릭 메뉴나 편집 도구의 **다음 단계 추가**는 새 단계와 연결선을 함께 만듭니다.

선은 요소에 붙어서 함께 움직입니다. 선을 클릭하면 오른쪽에서 다음 항목을 바꿀 수 있습니다.

- 선 위의 설명
- 직각·직선·곡선
- 끝 화살표·양쪽 화살표·화살표 없음
- 색상·선 두께·점선

직각 연결선은 도형·이미지·텍스트 요소를 피해 자동으로 돌아갑니다. 영역 상자는 내부 연결을 허용하고 제목 부분을 피합니다. 자유선 자체와 다른 연결선은 장애물로 취급하지 않습니다.

선을 선택하면 **모서리와 선 중간의 주황 손잡이**가 나타납니다. 손잡이를 드래그하면 원하는 위치를 거치는 직각 경로로 바뀝니다. 여러 지점을 순서대로 조절할 수 있으며 선마다 최대 32개 지점을 보관합니다. 장애물 안으로 손잡이를 끌면 마지막 유효 위치를 유지합니다. **자동 경로로 되돌리기**는 수동 조절 지점을 지웁니다. Ctrl+Z로 경로 변경을 취소할 수 있습니다.

요소가 겹치거나 수동 조절 지점이 장애물 안에 놓여 통로가 없으면 선을 억지로 관통시키지 않고 **경로 없음**을 표시합니다. 이 표시를 클릭해 해당 선을 선택한 뒤, 겹친 요소를 옮기거나 자동 경로로 되돌리세요. 빠른 **자동 배치**는 서로 다른 그룹/요소 사이의 수동 경로를 초기화합니다. **업무 도구 → 자동 배치**에서는 수동 경로 보존 여부를 선택할 수 있습니다. 같은 그룹 내부의 조절 지점은 그룹 이동·정렬 시 함께 이동합니다.

연결선을 선택하고 Delete를 누르면 선만 삭제됩니다. 요소를 삭제하면 그 요소에 연결된 선도 함께 삭제됩니다.

## 정렬, 그룹, 영역 상자

정렬할 요소를 두 개 이상 선택한 뒤 속성 패널의 **정렬과 간격** 버튼을 누릅니다. 같은 간격으로 배치하려면 세 개 이상을 선택하세요. 그룹은 내부 요소의 상대 위치를 유지하는 묶음으로 다룹니다.

빠른 **자동 배치**는 연결 관계를 기준으로 왼쪽에서 오른쪽으로 정리합니다. 여러 배치 방식과 미리보기는 **업무 도구 → 자동 배치**에서 사용합니다. 두 개 이상을 선택하면 선택 범위에 적용합니다. 전체 보드를 배치하려면 선택을 해제한 뒤 누르세요. 하나만 선택하면 안내 메시지를 표시합니다. 독립적인 설명 텍스트와 영역 상자는 전체 자동 배치에서 기본적으로 제외됩니다. 결과는 Ctrl+Z로 되돌릴 수 있습니다.

Shift+클릭 또는 빈 곳 드래그로 여러 요소를 선택한 뒤, 오른쪽 **여러 요소 묶기 → 그룹 만들기**를 누르세요. **그룹(Ctrl+G)**은 여러 요소를 함께 선택·이동하기 위한 기능입니다. **그룹 풀기(Ctrl+Shift+G)**로 개별 요소로 돌아갑니다. **영역 상자(F)**는 자료 묶음에 제목과 배경을 붙이는 요소입니다. 상자의 제목이나 테두리를 잡고 이동하면 그 안에 완전히 들어 있는 잠기지 않은 요소도 함께 이동합니다.

**잠금(Ctrl+L)**을 적용하면 해당 요소의 이동·크기·내용 변경과 삭제를 막습니다. 다시 Ctrl+L을 누르거나 속성에서 잠금을 풀 수 있습니다. 연결선 자체는 별도로 편집할 수 있습니다.

## 이미지 넣기와 보관

지원 형식은 PNG, JPG, WebP, GIF입니다. 세 가지 방법으로 추가할 수 있습니다.

| 방법 | 동작 |
| --- | --- |
| Ctrl+V | 캡처나 이미지로 복사한 클립보드 내용을 작업지 중앙에 추가 |
| 파일 드롭 | 이미지 파일을 놓은 위치에 추가 |
| 이미지 도구 / Ctrl+Shift+I | 파일 선택창에서 한 개 또는 여러 개 선택 |

한 번에 최대 20개를 가져올 수 있으며 원본 파일 하나는 25MB, 약 6,400만 화소 이하여야 합니다. 추가할 때 긴 변이 최대 2,400px가 되도록 줄이고 다시 인코딩합니다. 용량에 따라 더 축소될 수 있습니다. 원본 해상도, 메타데이터, 원본 파일, GIF 애니메이션을 유지하는 보관함은 아닙니다.

문서에는 변환된 이미지 데이터가 포함되므로 `.agentsketch` 파일만 다른 PC로 옮겨도 그림이 따라갑니다. 화면에 64개를 넘는 이미지가 동시에 보이면 가운데에 가까운 이미지를 먼저 표시합니다. 일부가 자리 표시자로 보일 때는 그 부분을 확대하거나 화면을 이동하세요. 저장·내보내기에서는 화면 표시 제한과 관계없이 전체 이미지를 처리합니다.

문서 파일은 80MB까지 읽고 저장할 수 있습니다. 내부 이미지 데이터 합계에도 한도가 있으므로 이미지가 많은 보드에서는 추가를 제한할 수 있습니다. 한 보드에 자료를 모두 모으기보다 보고나 주제별로 파일을 나누면 탐색과 공유가 편합니다.

## 파일 저장과 자동 복구

| 기능 | 보관 위치와 의미 |
| --- | --- |
| 저장 / Ctrl+S | 처음에는 경로를 선택하고, 다음부터는 같은 `.agentsketch` 파일을 갱신 |
| 다른 이름으로 저장 / Ctrl+Shift+S | 새 파일 경로를 선택하여 별도 사본 보관 |
| 자동 복구 | 최근 작업 복구 파일을 보관하고, 데스크톱에서는 저장 경로가 있는 문서의 최신 복구 사본도 구분해 보관 |
| 열기 / Ctrl+O | 저장한 `.agentsketch` 파일 선택 |

**자동 복구가 완료되어도 원래 열었던 문서 파일이 자동으로 갱신되지는 않습니다.** 보관할 버전이나 다른 PC에서 쓸 작업은 Ctrl+S로 파일을 저장하세요.

보드를 편집한 뒤 **새 보드**, **열기**, **예시로 시작하기**를 선택하면 현재 보드를 저장할지 묻습니다. **저장하지 않고 계속**을 선택하면 최근 자동 복구도 새 보드로 바뀝니다. 데스크톱의 문서 보관함에서 파일 저장 이력과 복구 사본을 확인할 수 있습니다. 보관량에는 제한이 있으므로 장기 보관할 문서는 별도 파일로 저장하세요.

앱을 정상적으로 닫을 때는 아직 입력 중인 내용을 포함해 마지막 상태를 복구 파일에 저장합니다. 다음 실행에서 이 상태를 엽니다. 강제 종료·전원 차단 직전의 입력까지 보장하는 기능은 아니므로 중요한 작업은 중간에 파일로 저장하세요.

복구 파일 위치는 `%APPDATA%\AgentSketch\recovery.agentsketch`입니다. 실행 취소 이력은 파일에 저장되지 않으며 다른 보드를 열거나 앱을 다시 실행하면 초기화됩니다.

요소 삭제에는 추가 확인창이 없습니다. 잘못 삭제했으면 바로 **Ctrl+Z**로 되돌리세요. 잠긴 요소는 삭제되지 않습니다. 원본 파일을 남기려면 같은 파일에 Ctrl+S를 누르기 전에 **다른 이름으로 저장**을 사용하세요.

## 내보내기

오른쪽 위 **내보내기**는 작업지의 PNG·SVG·이미지 PDF를 빠르게 출력합니다. 선택 영역, 문서 페이지별 출력, 검색 가능한 PDF와 PowerPoint는 **업무 도구 → 보고와 호환**을 사용하세요. 편집 도구, 격자, 선택 테두리는 출력하지 않습니다.

| 형식 | 용도와 특성 |
| --- | --- |
| PNG | 문서·PPT·메신저에 넣는 이미지. 큰 보드는 최대 변 8,192px 및 약 3,200만 화소 안으로 축소 |
| SVG | 도형·선·글자를 벡터로 저장. 포함된 사진은 래스터 이미지이며 글꼴 모양은 여는 환경에 따라 달라질 수 있음 |
| PDF | 보드 전체를 한 장의 이미지로 배치한 PDF. 글자를 별도로 선택하거나 검색하는 문서 형식은 아님 |

나중에 수정할 수 있는 원본은 `.agentsketch`입니다. PNG·SVG·PDF 내보내기와 원본 저장을 함께 해두세요.

| 속성 패널 접기·펼치기 | 캔버스에 초점이 있을 때 Tab |

## 확인할 점

- 자동 복구 실패 메시지가 나오면 Ctrl+S로 파일을 저장하고 저장 위치의 공간·권한을 확인하세요.
- 이미지를 붙일 수 없다면 PPT에서 **그림으로 복사**하거나 Windows 캡처로 다시 복사해 보세요. 일반 텍스트는 텍스트 요소로 붙습니다.
- 선이 보이지 않거나 요소가 멀리 나갔다면 **전체 보기**를 누르거나 레이어에서 해당 요소를 찾아 더블클릭하세요.
- 배경 이미지가 자꾸 움직이면 해당 이미지를 선택해 **잠금**을 적용하세요.
- 그룹 안의 요소만 고치려면 **업무 도구 → 페이지와 그룹**의 계층 트리나 **그룹 안의 요소 선택**을 사용하세요.

### 자료와 준비 상태

1. 자료에 해당하는 상자나 이미지를 선택하고 **자료와 준비 상태**에서 종류를 **자료**로 지정합니다.
2. 담당자, 출처 시스템, 파일·폴더·웹 주소, 버전, 재확인 기한과 설명을 입력합니다.
3. **원본 확인**은 로컬 파일의 존재와 변경 정보를 확인합니다. 폴더 내용이나 업무 데이터의 정확성은 검사하지 않습니다. 웹 주소는 형식만 확인하며 서버에 접속해 내용을 읽지 않습니다.
4. 내용을 직접 검토한 뒤 확인자와 확인 기록을 남깁니다. 파일이 존재한다는 이유만으로 확인 완료가 되지 않습니다.
5. 절차에 연결한 선의 관계를 필수·대체·선택·참고·출력 중에서 정하고, 절차의 조건을 **모두 필요** 또는 **하나 이상 필요**로 정합니다.
6. 준비 상태 목록에서 미확인 자료, 기한 경과, 버전·원본 지문의 변경, 순환 조건을 확인합니다. 선행·후행 관계 선택으로 자료의 사용처를 따라갈 수 있습니다. 다른 페이지의 관련 요소도 목록에 표시하며, 항목을 누르면 그 페이지로 이동합니다. 숨긴 레이어나 접힌 그룹에 있으면 해당 항목을 보이게 전환합니다.

업무별 값은 **사용자 정의 필드**에 추가합니다. 예를 들어 절차에 `보고주기=정기`를 넣고, 연결선을 선택한 뒤 **조건부 적용**에서 해당 절차·필드·일치·`정기`를 지정하면 이 값일 때만 선행 관계를 계산합니다. 요소마다 필드는 최대 32개입니다. 수동 확인 상태도 조건에 사용할 수 있습니다. 비교는 값의 정확한 일치 또는 불일치이며 조건이 맞지 않으면 해당 관계를 준비 계산에서 제외합니다. 참조 요소나 필드가 누락되면 필수·대체 관계는 확인 전까지 준비를 막습니다. 빈 문자열과 미등록 값은 다르게 처리합니다.

원본 변경 확인은 버튼으로 수행하거나, 자료를 선택하고 **원본 변경 감시**를 켤 수 있습니다. 감시는 앱이 열린 동안 로컬 파일·폴더 최대 20개를 60초마다 5개씩 확인합니다. 전체 확인에는 최대 4분이 걸리며 문서를 바꾸면 중지합니다. 웹·업무 서버와 폴더 내부를 재귀 감시하지 않습니다. 32MiB를 넘는 파일은 내용 전체의 지문 대신 크기와 수정 시각을 비교합니다. **재확인 주기(일)**는 확인일을 기준으로 준비 상태에 반영하며 별도 예약 알림은 보내지 않습니다.

출처 경로 등록과 파일 첨부는 별개입니다. **첨부와 경로**에서 자료 파일을 넣으면 `.agentsketch`에 함께 보관됩니다. PDF, XLSX, DOCX, PPTX, TXT, CSV와 이미지 형식을 지원하며 파일당 5MiB·문서 전체 20MiB·최대 100개입니다. TXT·CSV는 UTF-8을 사용하며 매크로가 포함된 Office 파일은 첨부할 수 없습니다. 첨부 목록의 **파일 저장**으로 다른 PC에서 꺼내 사용할 수 있습니다. **원본 경로 다시 연결**은 경로 앞부분을 바꿀 항목을 미리 확인한 뒤 적용합니다. 실제 원본 파일을 이동하지 않으며 확인 완료 자료는 재확인 상태로 바뀝니다.

**단계의 준비 상태와 실제 업무 완료는 다릅니다.** 선행 자료가 준비되었다고 보고·승인이 자동 수행되지는 않습니다. AI 응답과 OCR 결과도 사용자가 원본과 확인해야 합니다.

### 배치·페이지·그룹

**자동 배치** 패널에서 좌→우, 위→아래, 트리, 방사형, 담당자별 배치를 고를 수 있습니다. 간격, 현재 위치 유지, 수동 경로 보존, 같은 행·열 제약을 설정하고 **미리보기**를 만든 뒤 **적용**하세요. 배치 대안의 **연결 순서로 펼치기 / 반대 순서로 펼치기**를 바꿔 차례로 비교할 수 있습니다. 미리보기 선은 관계만 표시하고 적용 후 실제 직각 경로를 계산합니다. 선택한 요소가 있으면 선택 범위를, 없으면 현재 페이지의 보이는 범위를 대상으로 합니다. 미리보기 뒤 문서가 달라지면 다시 계산해야 합니다. 큰 배치는 취소할 수 있습니다.

**페이지와 그룹**에서 페이지를 추가하거나 선택 요소를 다른 페이지로 옮깁니다. 그룹은 이름·설명·상위 그룹을 지정하고 접거나 펼칠 수 있습니다. **그룹과 내부 요소** 계층 트리에서 하위 그룹과 구성 요소를 찾아 선택합니다. 트리의 방향키로 이동·펼치기·접기를 할 수 있습니다. 목록 접기는 탐색 표시를 정리하는 기능이고, 그룹 접기는 작업지의 표시를 줄이는 기능입니다. **그룹 안의 요소 선택**으로 그룹을 풀지 않고 내부 요소를 선택합니다. 그룹 크기는 비율로 변경합니다. Alt를 누르고 요소를 다른 그룹의 요소 위로 놓으면 그 그룹에 편입하고, 빈 곳에 놓으면 그룹에서 분리합니다. 레이어에는 캡처·배경·설명처럼 역할별 요소를 넣고 숨기거나 잠글 수 있습니다.

보기는 북마크로, 반복 사용하는 선택 묶음은 개인 보관함으로 저장합니다. 개인 보관함은 이 PC의 앱 저장소를 사용하며 최대 20개·약 5MB로 제한합니다. 중요한 자료의 장기 보관은 `.agentsketch` 파일을 사용하세요.

### 편집 도구

이미지를 선택하면 자를 범위를 백분율로 입력하거나 다른 이미지로 교체할 수 있습니다. 이미지 교체는 요소의 위치·설명·연결을 유지하고 기존 자르기는 초기화합니다. **이미지 내용 회전**은 상자 안의 내용만 돌리며 상자와 연결점은 고정됩니다. 회전 후 상자 밖에 나간 부분은 잘립니다.

선택한 연결선의 시작·도착 요소, 연결 면, 면 위 위치, 선 위 설명 위치를 바꿀 수 있습니다. 설명 배경색과 방향(-90°·0°·90°)도 지정합니다. 경유점 목록에서는 개별 지점을 삭제합니다. **구간 양끝 고정**을 펼쳐 가로·세로 구간을 선택하고 **선택 구간 양끝 고정**을 누르면 양끝을 경유점으로 보관합니다. **양끝 해제**로 해당 두 경유점을 제거합니다. 이후 중간에 장애물이 생기면 안전하게 우회하고, 경유점 자체가 막혀 경로가 없으면 경로 없음 상태를 표시합니다. 서식 복사·붙이기는 앱 실행 중에 유지됩니다.

**기본 서식으로 저장**은 선택한 요소 또는 연결선의 외형을 이 기기에 보관하여 새 요소에 적용합니다. 기존 선택에는 **기본 서식 적용**을 사용하고, **기본 서식 초기화**로 지울 수 있습니다. 도형·연결선 기본값은 따로 저장하며 글 내용·출처·자료 정보는 저장하지 않습니다.

부분 글자 서식은 **내용과 부분 서식**에서 내용을 적용한 뒤 범위를 지정하거나 글자를 선택해 바꿉니다. 체크리스트는 한 줄에 한 항목을 쓰고 `[x]` 또는 `[ ]`로 상태를 지정합니다. 표는 Excel에서 복사한 탭 구분 내용을 붙일 수 있으며 첫 줄을 열 제목으로 사용합니다.

### 문서 탭·보관함과 출력

작업지 위의 **새 문서** 버튼으로 탭을 추가합니다. 최대 5개·탭 복구 합계 60MiB까지 보관하며, 사용하지 않는 탭은 디스크에 두고 전환할 때 읽습니다. 탭 복구와 원래 문서 파일 저장은 별개이므로 중요한 작업은 Ctrl+S로 저장하세요. 탭을 닫으면 해당 탭 복구 사본도 제거되므로 저장하지 않은 작업의 확인 안내를 읽으세요. 앱을 정상 종료할 때 열린 탭을 복구 저장합니다.

**현재 작업 보관**은 현재 상태의 복구 사본을 만듭니다. 최근 파일 옆 **이력**에서 이전 저장 사본을 확인합니다. 사본을 열어도 원본 파일을 바로 덮어쓰지 않으며, 전환 전 현재 작업도 사본으로 보관합니다. 데스크톱 저장 이력은 파일별 최대 12개와 보관 용량 한도 내에서 순환 관리합니다. 브라우저 미리보기의 수동 복구 사본은 최근 10개입니다. 이력 보관은 외부 백업을 대신하지 않습니다.

**보고와 호환**에서는 전체 문서 또는 선택 범위, A4·A3, 방향, 문서 페이지별 분리를 선택합니다. 검색 가능한 PDF는 한글 Regular·Semibold 글꼴을 포함하며 부분 글자 굵기·색상·크기와 표·체크리스트를 보존합니다. PDF의 링크 글자는 밑줄로 표시하며 클릭 기능은 포함하지 않습니다.

PDF 배치를 **보드 한 장에 맞추기** 또는 **원본 크기로 여러 장**으로 선택합니다. 여백은 기본 10mm이며 5~40mm로 조절합니다. 여러 장 출력 배율은 25~200%이고 100%는 보드 96px를 1인치로 출력합니다. 왼쪽부터 오른쪽, 위에서 아래 순서로 나누며 설정에 맞는 예상 페이지 수를 표시합니다. 전체 100페이지 한도를 넘으면 배율이나 출력 범위를 줄이세요.

**자료 준비 현황 보고서** HTML은 내부 메모와 메모 도형을 기본 제외합니다. 필요한 경우 **보고서에 내부 메모 포함**을 직접 선택하세요. 검토 댓글은 보고서에 포함하지 않습니다. PDF·PPTX는 보드의 메모 도형도 출력하므로 필요한 요소만 선택하여 내보내세요. PPTX의 도형·글·이미지·표와 선 조각은 편집 가능하지만, 선은 PowerPoint의 자동 연결선이 아닙니다. Pretendard가 없는 PC에서는 PowerPoint 글꼴이 대체될 수 있습니다.

CSV는 요소·연결·업무 정보를 교환하는 형식입니다. `.xlsx` 파일을 직접 가져오지는 않습니다. draw.io 교환은 기본 도형과 연결선 중심이며 비압축 XML 첫 페이지를 읽습니다. 이미지·그룹·레이어·업무 속성처럼 변환되지 않는 항목은 안내를 확인하세요. 완전한 원본은 `.agentsketch`로 보관합니다.

선택 원본·CSV·draw.io를 저장할 때 연결 조건이 선택 밖 자료를 참조하면 해당 자료도 함께 포함되고 추가 개수를 표시합니다. PDF 등 그림 출력의 선택 범위는 바뀌지 않습니다. 조건식을 보존하려면 `.agentsketch` 또는 CSV를 사용하세요.

### OCR·AI·공동 작업

**이미지 글자 읽기**는 선택 이미지에 대해 Windows 내장 OCR을 요청할 때만 실행합니다. Windows에 설치된 인식 언어를 사용하고, 자르기·회전 전의 저장 이미지를 읽습니다. 읽은 글자를 수정하고 **텍스트 요소로 추가**를 눌러 반영하세요. 숫자·단위·표의 인식 결과는 원본과 대조해야 합니다.

**검토와 발표**의 AI 기능은 사용자가 지정한 Chat Completions 호환 주소와 모델을 사용합니다. 전송할 JSON 내용을 먼저 표시하고 사용자가 전송에 동의한 뒤 요청합니다. API 키는 앱 실행 중 메모리에만 유지하며 파일에 저장하지 않습니다. 외부 서비스의 인증·비용·정책은 해당 서비스 설정을 따릅니다. 자동으로 자료를 전송하거나 AI 초안을 적용하지 않습니다.

**공동 작업**은 Windows 앱에서 직접 시작합니다. 기본 공유는 이 PC에서만 접속할 수 있으며, **다른 PC 접속 허용**을 선택한 경우 사설망 HTTP로 연결할 수 있습니다. 신뢰할 수 있는 네트워크에서만 사용하고 공유 키를 안전하게 전달하세요. 공유 키를 가진 사용자는 보드를 읽고 편집할 수 있습니다. 연결 후 수동 동기화 또는 3초 간격 자동 동기화를 선택합니다. 동시에 바뀐 문서는 자동 병합하지 않고 충돌을 알려 최신 보드 적용 여부를 선택하게 합니다. 공유 보드는 20MB 이하로 제한됩니다. 사용을 마치면 **연결 종료**를 누르세요.

이번 확장의 구현 범위와 남은 항목은 [업그레이드 범위](업그레이드범위.md)를 참고하세요. 실행·성능 검증 결과는 별도 검증 문서에 기록합니다.


### 설치와 이전 버전

설치 배포본 `AgentSketch-Setup.exe`는 현재 사용자 폴더에 설치하며 관리자 권한을 요구하지 않습니다. 파일 연결·바로가기·이전 실행 파일 보관을 선택할 수 있습니다. 업데이트는 기존 창을 닫고 새 설치 파일을 실행합니다. **이전 버전으로 되돌리기**는 업데이트 때 보관한 실행 파일을 다시 사용하는 기능이며 문서와 복구 자료를 삭제하지 않습니다.

이번 설치 파일에는 코드 서명이 없습니다. Windows가 확인되지 않은 게시자로 표시할 수 있습니다. 자동 업데이트 서버는 사용하지 않습니다. 새 기능으로 저장한 문서를 구버전에서 다시 저장하면 새 속성을 잃을 수 있으므로 실행 파일을 되돌리기 전에 원본 문서를 별도로 보관하세요.

### 상세 문서를 카드로 연결하기

Windows 앱 왼쪽 도구 막대의 **문서 카드 추가**에서 기존 `.agentsketch` 파일을 선택합니다. 통합 보드에 주황색 문서 카드가 만들어지며 다른 요소처럼 이동·크기 조절·그룹·연결선을 사용할 수 있습니다.

카드를 **더블클릭**하거나 선택 후 **Enter**, 속성 패널의 **상세 문서 열기**를 누르면 상세 문서가 새 탭으로 열립니다. 같은 경로의 문서가 이미 열려 있으면 그 탭으로 이동하며 미저장 편집을 유지합니다. 통합 문서 탭을 누르면 돌아옵니다. 상세 문서에서 Ctrl+S는 그 원본 파일을 저장합니다.

카드는 파일의 절대 경로만 보관하며 상세 내용을 복제하거나 미리 불러오지 않습니다. 탭은 기존 최대 5개·복구 합계 60MiB 한도를 공유합니다. 파일 이동·다른 이름 저장·다른 PC 이동 후에는 카드의 **다시 연결**로 경로를 바꾸세요. 파일이 없거나 손상되면 현재 문서를 유지하며 오류를 안내합니다. 우클릭 **문서 연결 해제**는 원본 파일을 삭제하지 않습니다. 카드 표시 문구는 통합 보드에서 따로 편집하며 상세 문서 제목과 자동 동기화하지 않습니다.
