# AgentSketch 업그레이드 범위

기준일: 2026-10-30. 이 문서는 요청한 상위 제품 수준의 목표 목록과 현재 소스 구현을 비교합니다. 기능이 코드에 있는 것과 실제 환경에서 검증된 것은 구분합니다. 실행 검사·성능 수치·배포 파일 정보는 `검증결과.md`를 기준으로 확인하세요.

이번 확장은 편집기를 업무 자료 추적 도구로 넓힌 버전입니다. 아래에 구현한 기능, 지원하는 방식과 남아 있는 제약을 구분했습니다. 경쟁 제품 전체와의 동등성을 검증한 결과는 아닙니다.

직각 선의 **구간 양끝 고정**은 해당 구간의 양끝을 경유점으로 유지합니다. 이후 사이에 장애물이 생기면 안전한 직각 경로로 돌아가며, 경유점 자체가 막혀 유효 경로가 없으면 경로 없음 상태를 표시합니다.

## 정확히 구분해야 하는 상태

- **출처가 있음:** 경로나 URL이 입력되어 있습니다.
- **원본이 존재함:** 요청한 시점에 로컬 파일·폴더를 찾았습니다. URL은 주소 형식만 확인합니다.
- **원본 변경 정보가 같음:** 마지막 확인한 크기·수정 시각 또는 파일 지문과 비교한 결과입니다.
- **내용 확인 완료:** 사용자가 확인자·버전·기록을 남겼습니다. 앱이 업무 내용을 대신 검증한 상태가 아닙니다.
- **절차 준비됨:** 기록된 선행 조건이 충족됩니다. 실제 보고나 승인이 완료된 상태와 다릅니다.

원본 확인은 버튼을 누르거나 선택한 자료의 변경 감시를 직접 켠 경우 수행합니다. 감시는 앱이 열린 동안 최대 20개 로컬 파일·폴더를 60초마다 5개씩 확인하며, 20개 전체를 확인하는 데 최대 4분이 걸립니다. 문서가 바뀌면 감시를 중지합니다. 32MiB 초과 파일은 내용 전체 해시 대신 크기·수정 시각을 사용하며 폴더 내부 자료를 재귀 검증하지 않습니다. 재확인 주기는 준비 상태 계산에 사용하지만 별도의 예약 알림을 보내지는 않습니다.

## 저장 형식과 호환

`.agentsketch`는 이미지가 포함된 JSON 문서입니다. 기존 버전 1 기본 필드를 유지하고 자료 정보·페이지·레이어·그룹·검토 등의 선택 필드를 추가했습니다. 이전 기본 문서는 새 앱에서 읽을 수 있습니다. 반대로 구버전 앱으로 새 문서를 다시 저장하면 구버전이 모르는 새 필드가 사라질 수 있으므로 새 기능을 사용한 문서는 새 실행 파일로 편집하세요.

이미지와 첨부 데이터는 이력에서 문자열을 공유하고 디코딩 캐시는 제한합니다. **첨부와 경로**에서 넣은 PDF·Excel·Word·PowerPoint·텍스트·CSV·이미지는 `.agentsketch`에 본문이 포함됩니다. 파일당 5MiB, 문서 합계 20MiB·최대 100개입니다. TXT·CSV는 UTF-8이며 매크로가 포함된 Office 파일은 첨부하지 않습니다. 경로만 등록한 원본은 자동으로 첨부되지 않습니다. 다른 PC로 이동할 때는 첨부 여부를 확인하고 필요하면 출처 경로를 일괄 바꾸세요.

CSV는 AgentSketch 요소·연결·업무 속성의 교환용입니다. draw.io는 비압축 XML 첫 페이지의 기본 도형·평문·색상·연결·경유점 중심이며 이미지·그룹·레이어·업무 정보 일부는 변환 경고를 표시합니다. 변환된 파일을 완전한 원본 보관 형식으로 사용하지 마세요.

선택 원본·CSV·draw.io 내보내기는 연결 조건이 참조하는 선택 밖 자료를 함께 포함하고 추가 개수를 표시합니다. PDF 등 그림 출력의 선택 범위는 유지합니다. 조건식은 `.agentsketch`·CSV에서 보존하며 draw.io 변환에서는 손실을 안내합니다.

PPTX의 선은 편집 가능한 선 조각이며 PowerPoint 도형에 붙어 자동 이동하는 커넥터가 아닙니다. PDF는 Regular·Semibold 글꼴을 포함하고 글자별 굵기·색상·크기, 표·체크리스트를 보존합니다. PDF의 링크 글자는 밑줄로 표시하지만 클릭 링크는 포함하지 않습니다. PPTX는 부분 서식을 보존하며 수신 PC의 글꼴 설치 상태에 영향을 받습니다. 내보내기 패널의 변환 경고와 검증 범위를 확인하세요.

PDF는 A4/A3·가로/세로, 여백 5~40mm, 한 장 맞춤 또는 배율 25~200%의 여러 장 출력을 지원합니다. 기본 여백은 10mm이며 100% 배율은 보드 96px를 1인치로 출력합니다. 예상 페이지 수를 표시하고 총 100페이지를 넘으면 범위나 배율을 줄이도록 안내합니다.

## 외부 연결과 실행 비용

기본 상태에서 업무 DB·API를 조회하지 않고 OCR·AI·공유 서버를 실행하지 않습니다. 내보내기 라이브러리는 해당 작업 시 불러오고, 큰 자동 배치는 이미지 데이터를 Worker로 복제하지 않습니다. 성능의 절대 상한이나 모든 보드에서의 일정한 메모리 사용을 보장하지 않습니다.

OCR은 Windows에 설치된 언어로 로컬 처리합니다. AI는 사용자가 지정한 호환 서비스 주소·모델·키와 전송 동의가 필요합니다. 키는 실행 중 메모리에 유지하고 문서에 저장하지 않습니다. 전송된 자료는 사용자가 지정한 서비스의 처리 정책을 따릅니다.

LAN 공유는 사용자 요청으로 시작하며 기본은 이 PC의 루프백 주소입니다. 다른 PC 접속을 허용하면 사설망 HTTP 서버를 사용하고 공유 키를 가진 사용자가 읽고 편집할 수 있습니다. 공유는 20MB 이하이며 3초 자동 동기화는 연결 중 사용자가 선택한 경우에만 작동합니다. 충돌은 자동 병합하지 않고 별도로 적용하게 합니다. 인터넷 공개 배포·방화벽 자동 변경·계정별 권한 관리 기능은 아닙니다.

## 남아 있는 호환·운영 범위

- 연결선은 같은 연결점·면의 분기 간격을 조정하지만, 서로 다른 끝점의 복잡한 공통 구간까지 모두 분리하지는 않습니다.
- draw.io의 압축 XML·여러 페이지 전체·고유 속성을 완전하게 왕복 변환하지 않습니다. Excel은 CSV 교환이며 XLSX 직접 가져오기는 없습니다. PPTX는 편집 가능한 출력이며 원본 PPTX를 직접 여는 편집기는 아닙니다.
- PDF에서 링크를 클릭하는 기능과 PowerPoint에서 도형 이동을 따라 붙는 커넥터는 제공하지 않습니다.
- 여러 PC·장시간 사용, 실제 외부 AI 인증, LAN 환경별 접속은 검증 문서에 기재한 범위와 구분합니다. 소스에 기능이 있다는 이유만으로 모두 실사용 검증되었다고 보지 않습니다.

설치 파일은 사용자와 정한 대로 코드 서명 없이 제공합니다. 자동 업데이트 서버를 운영하지 않으며 새 설치 파일로 업데이트합니다. 인증서 확보나 별도 서버 승인을 기다리는 상태가 아닙니다. 조직 계정별 권한이나 자동 병합 서버는 현재 LAN 공유와 다른 확장 선택지입니다.

## 연결 문서 카드
기존 .agentsketch를 경로 참조 카드로 추가하고 더블클릭/Enter로 별도 탭에서 엽니다. 같은 경로의 열린 탭 재사용, 미저장 편집 보존, 원본 저장, 다시 연결/연결 해제를 제공합니다. 상세 내용 자동 임베드·썸네일 동기화·파일 이동 자동 추적은 하지 않습니다. Windows 실행 파일에서 사용합니다.
